# Features
{: .no_toc }

This section contains one guide page per core EzLifesteal feature. Each page explains what the feature does, when to enable it, and the minimum config needed to get it running. The [Configuration](../configuration) section contains the exhaustive per-key YAML reference for each file.

---

## Feature list

| Feature | Summary |
|---|---|
| [Lifesteal](lifesteal) | Heart gain / loss on PvP kill and death, per-world rules, zero-heart policy |
| [Heart Items](heart-items) | Voucher item definitions, drops on kill, and crafting recipes |
| [Shop](shop) | GUI shop where players spend in-game currency on heart vouchers |
| [Kill Streaks](kill-streaks) | Threshold-based rewards for consecutive PvP kills |
| [Displays](displays) | Action bar, boss bar, and floating leaderboard hologram |
| [Revive Beacon](revive-beacon) | Beacon ritual that lets a player revive a banned teammate |
| [Beacon Spawn](beacon-spawn) | Plugin-managed beacon placement with countdown timer and region protection |
| [Smurf Detection](smurf-detection) | Flags and reviews suspected kill-farming behaviour |
| [Admin Bypass](admin-bypass) | Exempts staff from heart gain / loss during testing or moderation |
| [Storage](storage) | YAML or MySQL persistence for player profiles and ban records |
| [Integrations](../integrations) | Optional hooks for Vault, PlaceholderAPI, EzSeasons, WorldGuard, and EzCountdown — each with its own guide page |
